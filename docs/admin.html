About the data

Where these results come from.

Race Rank serves a cleaned, committed snapshot of HYROX results. Nothing is looked up live in your browser, and the site never scrapes hyrox.com directly.

Source

Results are imported from the independently maintained pyrox-client dataset — an unofficial, MIT-licensed HYROX results API covering seasons 1–9. Race Rank is not affiliated with HYROX.

What is stored

Only the fields needed to rank a finish: display name, nation, age group, gender, event, competition/tier, and finish time. No contact details, account data, or split-level information.

Cleaning

The importer drops placeholder entries and physically impossible finish times, de-duplicates doubles nations, and tags every row with a canonical competition type and tier so filters behave predictably.

Refresh & removal

The cache is rebuilt only by a maintainer from an authorised import. Before any production launch, confirm your source licence permits republication and publish a correction/removal contact.

Refresh the cache

  1. Install dependencies: python3 -m pip install -r requirements.txt.
  2. Import latest results: npm run refresh:pyrox -- --full --confirm-republication-rights.
  3. Clean & normalise: python3 scripts/clean_dataset.py.
  4. Validate, then commit & push: npm run validate-data.
